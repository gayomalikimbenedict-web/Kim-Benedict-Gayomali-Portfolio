# Kim Benedict Gayomali Portfolio

Welcome to the Kim Benedict Gayomali Portfolio project! This repository contains the source code for a personal portfolio website showcasing the skills and projects of Kim Benedict Gayomali, an AI Automation Specialist, GHL CRM Builder, and Web Developer.

## Table of Contents

## Project Overview

This portfolio website is designed to highlight Kim's expertise in AI automation, CRM building, and web development. It includes sections for projects, services offered, and a contact form for potential clients or collaborators.

## Features

- **Home**: A welcoming landing page with a brief introduction.
- **Projects**: A showcase of various projects completed by Kim, with descriptions and links.
- **Services**: Detailed information about the services offered by Kim.
- **About**: Background information and expertise of Kim Benedict Gayomali.
- **Contact**: A contact form for inquiries and communication.

## Technologies Used

- React
- TypeScript
- Vite
- CSS (with Poppins font)
- Various logos and tools for the marquee animation

## Setup Instructions

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/Kim-Benedict-Gayomali-Portfolio.git
   ```
2. Navigate to the project directory:
   ```
   cd Kim-Benedict-Gayomali-Portfolio
   ```
3. Install the dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm run dev
   ```
5. Open your browser and go to `http://localhost:3000` to view the portfolio.

## Usage

Feel free to explore the portfolio and reach out through the contact form for any inquiries or collaboration opportunities.

# Kim Benedict Gayomali, portfolio v2

Portfolio of Kim Benedict Gayomali (Sechurplets Studio). Built on the portfoliov2-template layout, with this site's own content, navy and cyan colors and the Manrope typeface.

## Run it

```
npm install
npm run dev
```

Open http://localhost:5190. Build for production with `npm run build` (it type-checks first). Node 20.19 or newer.

## Where things live

- All copy is in `src/content/`: `site.ts` (name, links, photo), `home.ts` (hero, manifesto, Work chapters), `services.ts`, `method.ts` (How I work), `about.ts`, `proof.ts`, `showcase.ts`, `faqs.ts`, `legal.ts`.
- Pictures and the Showcase film are in `public/images/` and `public/media/`. The two walkthrough pages are `public/projects/*.html`.
- Colors are tokens in `src/styles/tokens.css`. The font is set in `src/styles/index.css` and loaded from Google Fonts in `index.html`.
- `src/content/automation.ts` and `src/features/home/automation/` are left over from the template. The Home page no longer shows the automation diagram, so they are unused and can be deleted.

## Deploy

`vercel.json` sends every path to `index.html` so routes like `/work/walkthroughs` load on refresh. Files in `public/` are served first.
